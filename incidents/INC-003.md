# INC-003: Shared Folder Access Denied due to Missing NTFS/Share Permissions

## Executive Summary
* **Incident ID:** INC-003
* **Ticket Reference (GLPI):** #5
* **Category:** System / File Sharing & Permissions
* **Requester:** `hr.sara`
* **Target Resource:** `\\DC01\HR-Share` (Workstation `WIN-USER-01`)
* **Severity / Priority:** Medium (P3)
* **ITIL v4 Lifecycle Phase:** Incident Management — Restoration of Service

---

## 1. Incident Description & Detection
User `hr.sara` reported an inability to open the HR department network repository `\\DC01\HR-Share` from workstation `WIN-USER-01`.

* **Symptom:** Windows Network Error dialog: *"Windows cannot access \\DC01\HR-Share. You do not have permission to access \\DC01\HR-Share."*
* **Root Cause Analysis (RCA):** Inspection on file server `DC01` revealed that while the share existed, neither the explicit user account `hr.sara` nor the Active Directory group `HR-Department` had been granted adequate Access Control List (ACL) entries under NTFS / Share Security settings.

## 3. Remediation & Workflow Executed

1. **Ticket Logging (GLPI):** Logged ticket under `System / File Sharing`, assigned to `it.adam`.
2. **Access Control Audit (`DC01`):**
   * Examined `C:\HR-Share` properties via File Explorer.
   * Confirmed missing explicit Read/Modify permissions in both **Share Permissions** and **NTFS Security** tabs.
3. **Permission Remediation:**
   * Updated NTFS ACLs to grant `hr.sara` (or `HR-Department` group) **Modify**, **Read & Execute**, and **List Folder Contents** rights.
   * Ensured Share level permissions align with NTFS restrictions.
4. **Validation:** Re-attempted accessing `\\DC01\HR-Share` from `WIN-USER-01` under `hr.sara` credentials. Access restored immediately.
5. **GLPI Closure:** Documented solution and marked ticket as **Solved**.

---

## 4. Post-Incident Recommendations
* Implement Security Group-based Access Control (e.g., `SG-HR-Share-RW`) rather than granting individual user permissions directly on folders to streamline RBAC administration.
